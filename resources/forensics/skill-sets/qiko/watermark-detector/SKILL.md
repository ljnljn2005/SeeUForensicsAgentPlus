# Watermark Detector（水印检测取证助手）— 检测 / 提取 / 溯源

## 概述

本技能对图片、视频、PDF 做水印取证分析，三合一能力：

- **检测**：判断文件是否含水印——明水印（可见）和暗水印（隐形）分别检测。
- **提取**：定位明水印区域并裁剪供查看；从暗水印中提取嵌入内容（ID/昵称/URL——即溯源线索）。
- **溯源**：平台特征匹配（抖音/快手等）、双图同源对比（判断两张图是否带同一水印）。

**输出**：结构化 JSON 报告 + Markdown 摘要 + 可视化证据图（频谱图、区域标记图、裁剪图）。证据图可直接用于取证展示。

**诚实的边界**（开始前告知用户）：
- 明水印**文字内容**的识别依赖 OCR。当前无 OCR 环境时，检测输出"区域定位 + 裁剪图 + 笔画结构分析"，文字内容需人工查看裁剪图；部署了 tesseract 的环境可自动提取文字。
- 暗水印检测是"特征发现"：检测到频谱亮点/可读嵌入内容 = 高置信有水印；无特征 = 可能无水印，也可能是未知算法（无法证明绝对无）。
- 溯源结论是"证据支持性"而非"法律定性"——报告供参考，正式司法用途请配合专业鉴定。

## 决策表

```
输入载体 × 检测目标 → 处理路径
─────────────────────────────────────────────
图片 + 全面检测  → 明水印检测 + 暗水印检测 + 平台匹配
图片 + 仅暗水印  → 频谱分析 + DCT/LSB 提取
图片 + 同源对比  → 双图指纹对比
视频 + 任意      → 抽帧检测（--probe 控制）
PDF  + 任意      → 页面渲染检测（--pages 控制）
─────────────────────────────────────────────
```

**启动前必做**：
1. 明确用户目标：想知道"有没有水印"（检测）、"水印里藏了什么"（提取溯源）、还是"两张图是否同源"（对比）。
2. 告知边界：明水印文字识别受 OCR 能力限制；暗水印"检测不到"不等于"不存在"。

## 核心工作流

1. **检测**：按决策表运行对应模块，收集证据（频谱图、区域标记、提取结果）。
2. **提取**：暗水印尝试多种方法回读内容；明水印输出裁剪图。
3. **报告**：生成 JSON（机器可读）+ Markdown（人读）+ 证据图。
4. **交付**：说明结论置信度与局限，给出建议（如需进一步人工鉴定）。

## 核心能力

### 1. 明水印检测（scripts/visible_detect.py）

- **区域定位**：顶帽/底帽变换提取"比邻域更亮/更暗的笔画结构" → 形态学合并 → 连通域分析，输出候选区域列表（bbox、面积占比、置信度）。
- **裁剪取证**：每个候选区域裁剪保存，供人工查看/放大鉴定。
- **结构分析**：笔画密度、宽高比等特征，区分"文字水印"与"随机图案"。
- **OCR 增强**（可选）：检测到系统有 tesseract 时自动对裁剪图做文字识别，输出提取文本。

### 2. 暗水印检测（scripts/invisible_detect.py）

三路证据交叉验证：

| 方法 | 原理 | 检出信号 |
|------|------|----------|
| FFT 频谱分析 | 周期水印在频谱形成对称亮点对 | 亮点数量与位置（可视化） |
| DCT 奇偶提取 | 与常见 8×8 DCT 嵌入格式兼容，多档强度尝试回读 | 提取到的文本内容 |
| LSB 最低位提取 | 最低有效位中的隐藏比特流 | 提取到的文本内容 |

- **置信度评估**：频谱亮点数 + 提取内容可读性（UTF-8 有效、长度合理）综合打分：high / medium / low。
- 提取内容即溯源线索（常见为 ID、昵称、日期、URL）。

### 3. 平台特征匹配（scripts/platform_match.py）

内置常见平台水印指纹库（抖音/快手角标+盲水印特征、扫描全能王角标等），匹配命中则提示"疑似来自 XX 平台"，辅助溯源方向。

### 4. 双图同源对比（--compare）

提取两张图的暗水印指纹（频谱特征 + DCT/LSB 提取内容），计算相似度，输出"同源/不同源/无法判断"及依据。适合验证"某图是否衍生自另一张"。

### 5. 视频 / PDF 检测

- 视频：`--probe N` 抽帧检测，聚合多帧结论（水印跨帧稳定出现 = 高置信）。
- PDF：渲染指定页（`--pages`）检测，支持逐页报告。

## 报告输出

JSON 报告结构（示例）：

```json
{
  "file": "photo.png",
  "visible": {
    "detected": true,
    "regions": [{"bbox": [501, 448, 219, 33], "area_pct": 1.7, "type": "text"}],
    "crops": ["photo_crop_0.png"]
  },
  "invisible": {
    "spectrum_peaks": 2,
    "dct_extract": "user_2026",
    "lsb_extract": null,
    "likelihood": "high"
  },
  "platform_match": ["douyin"],
  "conclusion": "检测到明水印与 DCT 暗水印，暗水印内容 user_2026，疑似抖音来源"
}
```

- 默认输出：`原文件名_report.json` + `原文件名_report.md` + 证据图（同目录 `_evidence/` 子目录）。
- 报告含"局限性声明"，取证场景务必保留。

## 工作流示例

**示例 1：检测图片是否带暗水印并提取内容**
输入：`photo.png`，用户想查"这图有没有隐藏追踪信息"
流程：`python3 scripts/wm_detect.py photo.png --type invisible` → 输出频谱图 + 提取结果 + JSON/MD 报告，报告显示提取到 `user_2026`。

**示例 2：两张图是否同源**
输入：`a.png` 与 `b.png`
流程：`python3 scripts/wm_detect.py a.png --compare b.png` → 输出指纹相似度与同源结论。

**示例 3：扫描件 PDF 取证明水印**
输入：`scan.pdf`（疑似扫描全能王水印）
流程：`python3 scripts/wm_detect.py scan.pdf --pages all` → 输出页面水印区域标记图与裁剪图。

## 适用场景

### 1. 版权与溯源取证
- 盗图投诉、侵权比对、素材授权核验：优先做明水印区域定位、暗水印回读、平台特征匹配。
- 需要输出可复核证据：原图哈希、裁剪图、频谱图、提取文本、报告哈希。

### 2. 平台来源与同源判断
- 判断图片/视频是否来自抖音、快手、扫描全能王等常见平台：使用平台指纹库与角标特征。
- 判断两张图是否同水印源：使用 --compare，输出频谱、DCT、LSB相似度。

### 3. 隐写与嵌套线索扩展分析
- 当水印检测未发现线索，但文件存在异常体积、文件尾附加数据、嵌套文件、二维码、缩略图异常、音频频谱异常、文档内嵌对象时，进入扩展隐写检查。
- 适用载体：图片、视频帧、PDF、音频、压缩包、Office/邮件、脚本、APK/EXE 资源。扩展检查应以授权与取证必要性为前提。
- 若委托方只要求原始水印检测，扩展隐写项应标记待人工裁决后再执行。

### 4. 输入优先级
| 输入 | 优先路径 | 适用条件 | 实战提醒 |
|---|---|---|---|
| 原始图片 | 明水印 + 暗水印 + EXIF/缩略图 | 用户要求查水印或溯源 | 避免截图与社交平台二次压缩 |
| 视频 | 抽帧 + 关键帧暗水印 | 片头/片尾/角标疑似平台水印 | 抽帧不足会漏掉间歇性水印 |
| PDF | 页面渲染 + 明水印 | 扫描件、导出件、合同截图 | 注意页面图层与注释层 |
| 音频 | 频谱 + 转写 + 尾部附加 | 语音、提示音、录音 | 频谱隐写需高分辨率 |
| 文档/压缩包/可执行文件 | 结构解析 + 嵌套提取 | 水印线索指向附件或资源 | 仅在授权范围内解包 |

### 5. 不适用与谨慎场景
- 不适用：去除水印、添加水印、生成伪造溯源信息、与普通图像内容识别混同。
- 谨慎：严重压缩、截图、旋转缩放、HEIC/WebP 转码、加密容器无密码、文件损坏严重。此类场景应降低置信度并说明局限。

## 使用步骤

### 0. 证据保全与受理登记
1. 创建只读原始副本与解析工作目录，禁止在原文件上直接修改。
2. 记录文件名、大小、SHA-256、接收时间、来源说明。
3. 若用户只提供截图或社交平台压缩图，先声明暗水印检出率会下降，并要求补充原图。

### 1. 文件类型与结构预检
- 使用 `file`、`exiftool`、`hexdump -C` 或 `xxd` 确认真实类型，避免仅依赖扩展名。
- 图片固定检查项：文件头魔数、IHDR/EXIF 尺寸、缩略图、色彩空间、透明通道、文件尾附加数据。
- 文件头修复：若 PNG 缺 IHDR、JPEG 缺 SOI/EOI，先做最小修复或转换副本；若图片高度异常，依据块结构与像素数据长度推算真实高度，修复后再检测。
- 嵌套扫描：对异常体积或文件尾数据使用 `binwalk`、`foremost` 做 carving；发现 PK、Rar、7z、PDF、ELF、MP3、ID3、PNG、JPEG 等魔数时单独提取。

### 2. 明水印检测
命令：`python3 scripts/wm_detect.py INPUT --type visible`
- 检查顶帽/底帽变换候选区域，优先复核四角、中心平铺、半透明图层、页面页眉页脚。
- 对每个候选区域输出 bbox、面积占比、裁剪图、笔画密度与宽高比。
- 有 tesseract 时执行 OCR；无 OCR 时保留裁剪图并做人工笔画复核。
- 对扫描件 PDF 先渲染高分辨率页面，再检测角标与平铺水印。

### 3. 暗水印检测
命令：`python3 scripts/wm_detect.py INPUT --type invisible`
- FFT：寻找周期水印形成的对称亮点对，记录亮点位置、数量与能量。
- DCT：按常见 8x8 块嵌入格式回读，尝试多档强度与常见同步头。
- LSB：提取最低有效位，检查可读 UTF-8、URL、ID、JSON、Base64、十六进制串。
- 置信度规则：可读内容 + 频谱亮点为 high；仅频谱亮点为 medium；仅弱 LSB 片段为 low。

### 4. 视频与 PDF
- 视频：`python3 scripts/wm_detect.py INPUT --probe N`，对片头、片尾、转场、关键帧补抽帧；角标稳定出现时提高置信度。
- PDF：`python3 scripts/wm_detect.py INPUT --pages all` 或 `--pages 1-10`；同时检查注释层、图层、附件与内嵌对象。

### 5. 平台匹配与同源对比
- 平台匹配：命中抖音、快手、扫描全能王等指纹时输出疑似来源，但不作为唯一结论。
- 同源对比：`python3 scripts/wm_detect.py A --compare B`，综合频谱相似度、DCT/LSB 内容、明水印布局输出同源/不同源/无法判断。

### 6. 扩展隐写与嵌套证据提取
以下流程在水印检测不足或线索指向嵌套载体时启用；若与原始技能边界冲突，标记待人工裁决，不自动覆盖现有范围。

#### 6.1 图片尾部附加数据与嵌入文件
- 适用条件：文件体积异常、IEND/EOI 后仍有数据、binwalk 命中压缩包/图片/音频/可执行文件。
- 操作：`binwalk INPUT`、`binwalk -e INPUT`、`foremost -i INPUT -o out`，必要时用 `dd` 按偏移切割。
- 识别特征：PK、Rar、7z、MZ、ELF、ID3、OggS、fLaC、PDF、base64 长串。
- 输出：提取文件、偏移、大小、SHA-256、与主文件关系。

#### 6.2 二维码、条码、缩略图与 OCR
- 适用条件：图中出现码状结构、EXIF 缩略图与主图不一致、明水印文字需要固定。
- 操作：`zbarimg INPUT`、`exiftool -b PreviewImage INPUT > thumb.jpg`、`tesseract crop.png out`。
- 识别特征：三个定位角、QR 版本区域、条码条纹、缩略图含原图未裁剪信息。
- 输出：解码文本、缩略图哈希、OCR 文本与置信度。

#### 6.3 音频隐写与频谱线索
- 适用条件：录音、语音消息、提示音、音频尾部异常。
- 操作：`ffmpeg -i INPUT out.wav`，生成频谱图；检查摩斯电码、窄带提示音、超高频段；必要时做音频 LSB 提取。
- 识别特征：频谱中出现规则点划、文字状亮斑、异常载波、静音段周期性脉冲。
- 输出：频谱图、时间戳、摩斯转写、音频哈希。

#### 6.4 压缩包、分卷与强制解压
- 适用条件：提取出 zip/rar/7z，或文件名暗示分卷。
- 操作：`7z l archive`、`7z x archive`、`unzip -o archive`；分卷先合并为单一逻辑文件再列目录。
- 识别特征：分卷后缀、缺失卷提示、加密标志、伪加密、异常压缩率。
- 输出：目录树、文件哈希、解压失败原因；密码破解仅在授权范围内进行。

#### 6.5 Office、邮件与内嵌文档
- 适用条件：docx/xlsx/pptx/eml/msg 或提取出 OLE/XML 文档。
- 操作：对 OOXML 用 unzip 检查 media、embeddings、comments、customXml；对 OLE 检查流对象与宏；对邮件解析正文、附件、内联资源与头信息。
- 识别特征：隐藏文字、白色字体、批注、修订记录、内嵌对象、附件魔数、异常 Content-ID。
- 输出：内嵌文件、宏摘要、隐藏文本、附件哈希。

#### 6.6 APK、EXE 与脚本资源
- 适用条件：线索指向应用资源、安装包、可执行文件或脚本注释。
- 操作：先做静态解包与字符串提取，检查资源目录、图标、assets、注释、配置段；需要逆向时再进入反编译流程。
- 识别特征：资源文件中嵌入图片/文本、注释中包含 URL/ID、字符串表出现 base64/hex、加壳导致熵值偏高。
- 输出：资源文件、字符串候选、偏移、置信度。

#### 6.7 二进制索引、异或词典与隐藏文件
- 适用条件：明文检索失败但存在可疑数据块。
- 操作：用 `strings`、`xxd` 定位可疑块，按常见 key 做异或还原；检查隐藏文件、点文件、ADS/资源 fork 等文件系统痕迹。
- 识别特征：重复块、熵值异常、索引表、字典文件、注释提示。
- 输出：候选 key、还原片段、偏移、验证方式。

### 7. 汇总输出
- 报告必须包含：输入哈希、检测方法、证据图、提取内容、置信度、局限性、待人工复核项。
- 对无法确认的线索，输出疑似原因与下一步建议，不输出绝对排除结论。

## 常见失败与处置

### 1. 输入质量导致漏检
| 现象 | 原因 | 处置 |
|---|---|---|
| 社交平台图查不到暗水印 | 二次压缩、缩放、截图破坏嵌入 | 要求原图；检查 EXIF/缩略图；降低置信度 |
| 视频抽帧未命中 | 水印间歇出现或抽帧过稀 | 增加 probe，重点抽片头片尾与转场 |
| PDF 渲染模糊 | 低分辨率渲染 | 提高渲染 DPI，逐页检查 |

### 2. 文件损坏与格式异常
| 现象 | 原因 | 处置 |
|---|---|---|
| 图片无法解码 | 文件头缺失、块损坏 | 修复文件头/高度后再检测，保留原始副本 |
| PNG 高度异常 | IHDR 被篡改 | 根据 IDAT 与像素长度推算高度，输出修复图与依据 |
| binwalk 提取失败 | 数据被截断或加密 | 记录偏移，尝试 foremost/手动 carving，不强行解释 |

### 3. 明水印误报与漏报
- 误报：高光、反光、纹理被识别为水印。处置：结合面积占比、位置、笔画连续性、多帧/多页稳定性复核。
- 漏报：低透明度水印与背景接近。处置：调整顶帽/底帽参数、增强对比、裁剪局部放大。
- OCR 错字：低分辨率或艺术字。处置：保留裁剪图，标注 OCR 置信度，禁止直接作为唯一证据。

### 4. 暗水印误判
- 频谱亮点但无可读内容：可能是纹理、压缩伪影或未知水印。输出 medium，并给出频谱图。
- LSB 提取乱码：JPEG 压缩或噪声导致。处置：尝试 DCT、多档强度；若无可读性则判 low。
- 提取内容像随机字符串：检查是否为 Base64、Hex、URL 编码、JSON；不要强行解读。

### 5. 嵌套提取失败
- 压缩包加密：无授权密码时停止爆破，记录加密标志与哈希。
- 分卷缺失：列出缺失卷，不生成虚假完整文件。
- Office 宏受保护：仅输出宏存在性与流结构，不执行宏。
- 邮件附件编码异常：按 MIME 边界重新切分，输出原始编码与解码结果。

### 6. 音频与二进制线索失败
- 频谱看不清：提高频谱分辨率，必要时分段放大。
- 摩斯电码误听：输出点划时间测量与人工复核建议。
- 异或还原无意义：停止扩大 key 范围，记录候选块与熵值。

### 7. 证据链与结论边界
- 所有提取文件必须记录来源文件、偏移、哈希与生成命令。
- 平台匹配只能输出疑似来源，不能替代人工鉴定。
- 同源对比若特征不足，应输出无法判断，避免强行同源。
