# 证据链报告（evidence-chain-report）

目标：产出一份**任何第三方都能按报告复现**的取证结论，而不是一段结论性叙述。

## 硬性规则

1. 没有证据支撑的句子不进结论区；放进「推测 / 待验证」区。
2. 每条结论至少关联一条证据记录，证据记录必须包含：
   - 源路径（绝对路径或相对工作区的稳定路径）
   - SHA-256（文件类证据；无法计算时写明原因）
   - 定位范围（行号 / 字节偏移 / 记录 ID / 时间戳）
   - 采集方式与时间（命令或工具 + 时区）
3. 不得补全不存在的日志行、文件内容、哈希或进程记录；缺失就写「缺失」并给出补充取证建议。
4. 报告只陈述实际执行过的操作；未执行的验证要标注「未执行」。
5. 涉密信息（令牌、密钥、个人身份信息）在正文脱敏，但保留「定位信息 + 哈希前缀」以便复核。

## 推荐结构

```markdown
# <案件 / 任务标题>

## 1. 范围与方法
- 取证范围：<磁盘 / 镜像 / 主机 / 时间窗>
- 采集方法：<只读挂载 / 镜像哈希 / 日志导出>
- 环境与工具版本：<...>
- 已知局限：<未覆盖分区、日志滚动、时区不确定等>

## 2. 结论
| # | 结论 | 置信度 | 证据 ID |
|---|------|--------|---------|
| C1 | ... | 高/中/低 | E1, E3 |

## 3. 证据清单
| ID | 类型 | 源路径 | SHA-256 | 定位 | 采集时间 |
|----|------|--------|---------|------|----------|
| E1 | 文件 | ... | ... | ... | ... |

## 4. 时间线
| 时间（时区） | 事件 | 证据 ID |

## 5. 推断与待验证
- H1（推测）：...；验证方法：...；所需证据：...

## 6. 复现命令
```bash
# 只读命令，逐条对应上面的证据 ID
```
```

## 交付前自查

- [ ] 结论区每行都能对应到证据 ID
- [ ] 每个证据 ID 都有路径 + 哈希（或缺失原因）+ 定位
- [ ] 时间戳都带时区与来源
- [ ] 事实与推断分区清晰
- [ ] 复现命令为只读，且不修改原始证据
- [ ] 没有声称执行过未执行的操作
