# 取证竞赛知识库检索

知识库是题解文档，不是比赛镜像；商业取证软件本体不在库内。

## 位置

- 默认 `D:/forensics-kb`（可用 `$SEEU_KB_DIR` 覆盖）；先 `ls` 确认结构。
- 命中文件后用 read 读全文再作答，不凭记忆。

## 检索

- 先用 `glob` 按竞赛名/年份找目录（如 `**/MeiyaCup2025*/**`、`**/*盘古石*/*`）；
- 再用 `grep` 搜题干关键词、人名、工具名、答案候选；
- 拿不准目录就 `bash` 跑 `find "$SEEU_KB_DIR" -maxdepth 3 -type d | head`。

## 输出

- 答案 + 来源文件相对路径（如 `writeups/MeiyaCup2025Individual.md`）+ 题解里的关键步骤；
- 题解文档与真实检材分开说：知识库没有镜像/检材本身，真要跑工具请让用户提供检材并切到对应预设；
- 查不到就写「知识库未收录」，不要编。
