本地模型设置

接入任何 OpenAI 兼容网关（GET /v1/models、POST /v1/chat/completions 支持 SSE）。 保存后写入 …，重启应用生效；官方 DeepSeek 账号链路保持可用，随时可关闭。

要带 /v1，不含 /chat/completions。例：http://127.0.0.1:11434/v1（Ollama）、http://127.0.0.1:1234/v1（LM Studio）。
多数本地网关不校验；不能留空时随便填一个（会写进子进程环境变量，不进补丁文件）。
ID 必须与网关 /v1/models 返回的一致；“设为默认”用第一个模型。
个人赛常用 131072（128k），团体赛 262144（256k）。
建议 8192；太大易触发网关 OOM。

    常见问题：

    · 「测试连接与能力自检」由外壳依次请求 /v1/models、一次非流式对话、一次带 ping_tool 的工具调用请求，不经过 dsh；失败通常是网关没起、端口不对或模型不支持函数调用。

    · 上下文窗口要按模型实际能力填；小于 48k 的模型还需要调小随包 preset 里的压缩余量（见 README §9.2）。

    · 保存后必须重启应用：dsh 只在启动时读取 local-model.patch.yml。
