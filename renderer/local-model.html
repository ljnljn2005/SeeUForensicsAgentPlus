本地模型设置

接入任何 OpenAI 兼容网关（GET /v1/models、POST /v1/chat/completions 支持 SSE）。 保存后写入 …，重启应用生效；官方 DeepSeek 账号链路保持可用，随时可关闭。

要带 /v1，不含 /chat/completions。例：http://127.0.0.1:11434/v1（Ollama）、http://127.0.0.1:1234/v1（LM Studio）。
多数本地网关不校验；不能留空时随便填一个（会写进子进程环境变量，不进补丁文件）。
ID 必须与网关 /v1/models 返回的一致；“设为默认”用第一个模型。不确定就点下方【从网关拉取模型列表】自动填。
个人赛常用 131072（128k），团体赛 262144（256k）。
建议 8192；太大易触发网关 OOM。
窗口档位： 一键填「上下文窗口 / 输出上限」，再按模型实测调整。
本机部署： 一键填模型、窗口、超时与开关（网关地址/Key 仍用自己的），保存后重启。
高级：超时与重试（低并发本地网关）
本地 32B 首次 prefill 可能几十秒，默认 600 秒。
两个分片之间最长等待；网关卡住时靠它中断。
dsh 默认 5 次；单机网关建议 3 次，避免排队更久。
会话标题用的小请求，默认 512，省本地算力。
Spark 单机（Qwen 系）选 chat template 才能看到思考过程；dsv4.1-flash 用 reasoning_content。
仅 chat-template 类格式会带进请求；写成 JSON 对象，留空不带。
留空即用默认值；改完记得保存并重启应用。

    常见问题：

    · 「测试连接与能力自检」由外壳依次请求 /v1/models、一次非流式对话、一次带 ping_tool 的工具调用请求，不经过 dsh；失败通常是网关没起、端口不对或模型不支持函数调用。

    · 上下文窗口要按模型实际能力填（128k 填 131072）；随包 preset 的压缩余量已按 8192 调好，32k 及以上的模型都能直接用，不需要再改配置（见 README §9.2）。

    · 保存后必须重启应用：dsh 只在启动时读取 local-model.patch.yml。
